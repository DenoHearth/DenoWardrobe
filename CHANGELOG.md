# Changelog

## 0.8.5 — 2026-10-20

- New **Sets** tab, built like the game's own Sets view: every class's dungeon, raid, Zul'Gurub, Ahn'Qiraj and PvP sets, Forever's own raid and PvP spec sets, and Forever's dungeon and crafted armour sets
- Class buttons to browse any class; your character wears the whole set on a turnable, zoomable model, with the set's pieces, quality borders and what you have collected
- Try On sends the set to the try-on model, Save as Outfit keeps it, Favourite puts it at the top of the list
- Only sets whose pieces the Forever server knows are listed; sets still to come on the server show up by themselves once it knows them
- Try-on model dresses looks the way the game's own transmog window does, and asks again for pieces still loading

## 0.7.1 — 2026-10-20

- The "Not shown on your character" note no longer shows on a tile before its look is drawn

## 0.7.0 — 2026-10-20

First public release.

- Wardrobe tab on the character screen: slots, armour and weapon type filters, search by name or source
- Your own character in every preview; a turnable, zoomable try-on model with the game's camera buttons
- Looks read live from AtlasLoot Forever, Forever Dungeon Journal and Questie, plus the world list and your own finds
- Previews dressed from the game's own item tables (no waiting for the server); names and quality remembered between sessions
- Placeholder, deprecated, test and above-level-60 items left out
- Named outfits: Try on, Equip, Transmog (at a transmogrifier), Rename, Delete, with pages
- Larger try-on strip icons with a quality coloured frame
